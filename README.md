# 🤖 AI Telegram Bot

This is a simple AI-powered Telegram bot built using Python.

The bot can chat with users, remember conversation history, and respond using a local AI model.

## 🚀 Features
- AI chat using a local model (Ollama)
- Remembers conversation (chat history)
- Separate memory for each user
- Telegram integration
- Commands:
  - /start – start the bot
  - /reset – clear chat memory

## 🛠️ Technologies Used
- Python
- python-telegram-bot
- Ollama (local AI)
- python-dotenv (for environment variables)
